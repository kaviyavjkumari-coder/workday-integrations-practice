# Workday Integrations Practice

Free, unofficial practice exam for the Workday Integrations certification.

- `index.html` — landing page
- `integrations-exam.html` — the practice exam (learning mode + timed exam mode)

## Publish with GitHub Pages

1. Create a new public repository on GitHub (e.g. `workday-integrations-practice`).
2. Click **Add file → Upload files**, drag in `index.html`, `integrations-exam.html` and this `README.md`, then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, set **Source** to *Deploy from a branch*, branch **main**, folder **/ (root)**, and **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repo-name>/`.

To update later, upload the changed file again with the same name.
