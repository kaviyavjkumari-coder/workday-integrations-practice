How to use it

  1. Open the practice exam and start in Learning mode, going domain by domain.
  2. Read every explanation — including for options you ruled out. The wrong answers teach the distinctions the real exam tests.
  3. Switch to Exam mode (20 questions, 60 minutes) once you're scoring well, and use the domain breakdown to find gaps.
  4. Repeat with fresh exams — questions and answer order are shuffled each time.
